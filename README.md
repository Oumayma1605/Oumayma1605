## 🚀 Featured Projects

### [Loss Given Default (LGD) Analysis](https://github.com/Oumayma1605/lgd-analysis)
Credit risk analysis on a real banking portfolio (~409,000 accounts, 2015–2021).
- **Problem:** estimate expected loss severity per economic sector to support provisioning decisions
- **Approach:** cleaned and consolidated multi-year exposure, default, and recovery data; computed LGD by sector and risk class
- **Result:** a reproducible LGD pipeline and reporting layer, with confidential source data excluded and a documented schema so the notebook can be re-run on any similarly structured portfolio
- **Stack:** Python, Pandas

### [Incident & Call Analytics](https://github.com/Oumayma1605/incident-call-analytics)
ITSM analytics project built on service desk incident data.
- **Problem:** surface recurring incident patterns and service quality issues hidden in ticket volume
- **Approach:** cleaned and anonymized ticket data, defined KPIs (volume, resolution time, operational performance), built supporting analysis and visuals
- **Result:** a repeatable analytics workflow that turns raw ticket exports into actionable service-quality indicators
- **Stack:** Python, Power BI, ServiceNow-style data

### [Azure Big Data Solution](https://github.com/Oumayma1605/Azure-big-data-solution)
End-to-end cloud data pipeline exercise on the Azure stack.
- **Problem:** move and prepare raw data for analytics at scale
- **Approach:** ingestion and orchestration with Azure Data Factory, storage in ADLS Gen2, transformation with Databricks (PySpark/SQL)
- **Result:** a working pipeline pattern from raw ingestion to analysis-ready data
- **Stack:** Azure Data Factory, ADLS Gen2, Databricks, SQL
